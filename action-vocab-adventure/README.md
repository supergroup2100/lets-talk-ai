# 🦫 咖皮巴拉動作大冒險 Capybara Action Adventure

對象：國小四～五年級｜單字 No.51–75（bake ~ sing，共 25 個動詞）

## 玩法
- 🗺️ RPG 地圖：5 個世界（甜點廚房 / 運動森林 / 偵探社 / 修理小店 / 生日派對）
- 🔊 聽力冒險：真人語音慢速發音，聽音選字
- 📖 情境任務：每個單字都有故事例句填空，每字只考一次不重複
- 🔍 好奇實驗室：三態變化、沉默字母、考試陷阱（enjoy+Ving、he has…）
- 👾 最終魔王：聽寫拼字，10 題對 8 題過關（須先集滿 5 世界）
- 🪙 金幣 / ⭐ 星星 / 🏅 徽章，localStorage 自動存進度（和數字村版分開存）

## 開啟方式
- 本地：直接用瀏覽器開 `index.html`
- 線上（GitHub Pages）：`https://<你的帳號>.github.io/lets-talk-ai/action-vocab-adventure/`

## 單字表
bake, blow, brush, celebrate, change, cheat, check, choose, clap, count, enjoy, enter, fix, forget, guess, have, hike, jog, knock, order, pack, pass, point, repeat, sing

用 vocab-adventure Skill 製作。主程式＋音檔、無廣告，可直接分享連結給孩子用平板玩。
