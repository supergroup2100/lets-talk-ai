# 咖皮隊長的社會科大冒險 🦫🗺️

四年級社會科**考前總複習 RPG** 遊戲，依據國小社會四上課本 **1-1～2-2** 內容設計。

## 遊戲內容

| 世界 | 對應課本 | 涵蓋重點 |
|------|----------|----------|
| 🗺️ 地圖村 | 1-1 從地圖看家鄉 | 地圖四要素、依主題選地圖、電子地圖、探索家鄉四步驟 |
| ⛰️ 地形山 | 1-2 家鄉的地形 | 平原／盆地／台地／丘陵／山地、地形與生活 |
| 🌦️ 氣候水鄉 | 1-3 氣候、水資源與生活 | 氣溫圖雨量圖、氣候與生活、水資源與水庫 |
| 🏠 古厝村 | 2-1 傳統住屋 | 石板屋、地下屋、竹管仔厝、土埆厝、三合院、古蹟保存 |
| 🍚 器物街 | 2-2 器物與生活 | 魚筌、木杵、土灶、物盡其用、塑膠與減塑 |

- **51 題**選擇題（每關 10～11 題），選項每次洗牌
- 答錯**立刻講解原因**（複習型設計，不是只記答案）
- TTS 自動唸題目（ zh-TW ），可按 🔊 重聽
- 每關星級評價（正確率 ≥90% 三顆星）、金幣、⭐、localStorage 進度儲存
- 📖 **考前重點整理**：5 個單元的速記筆記
- 👾 **叉叉魔王總決戰**：集滿 5 世界解鎖，10 題對 8 題、只有 2 次答錯機會

## 遊玩方式

```powershell
# 本機預覽（瀏覽器可能擋 file://，建議用這個）
python -m http.server 8000
# 瀏覽器開 http://localhost:8000/social4-rpg/
```

直接開 `index.html` 也可以。進度會自動儲存，改完內容請按 **Ctrl+F5** 強制更新。
